## 🎯 Tentang Proyek
Repositori ini dibuat untuk memenuhi tugas **Ujian Tengah Semester (UTS)** 
pada mata kuliah **Pengkodean**. Proyek ini mendemonstrasikan pemahaman dasar 
dalam membangun antarmuka web menggunakan **HTML & CSS**.

File utama dalam repositori ini adalah `index (2).html`, yang merupakan 
halaman web statis dengan desain modern dan responsif.

---

## ✨ Fitur & Teknologi
- **HTML5** — Struktur dasar halaman web.
- **CSS3** — Desain modern dengan gradient, animasi, dan glassmorphism.
- **Desain Responsif** — Tampilan menyesuaikan di HP, tablet, dan desktop.
- **Google Fonts (Poppins)** — Tipografi yang elegan.
